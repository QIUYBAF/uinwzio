# RNGtuber V1 Modular bootstrap

This branch is isolated from the repository's historical content. The bootstrap archive is the CRC-checked Google Drive checkpoint 02. GitHub Actions extracts it, preserves the project source under `RNGtuber_V1_Modular_2026-08-29/`, runs the Windows diagnostics and GUI smoke test, and uploads `RNGtuber_V1_Windows.zip`.

The bootstrap build deliberately does not regenerate approved runtime sprites from older heterogeneous source canvases.
