# AgentCut v0.2.0-alpha.10 — Reliability Gateway + UHD 4K60

Alpha 10 pauses feature expansion and focuses on two things: lowering AI control failure from naming/signature drift, and making 4K60 an actually tested render tier.

## Agent Reliability Gateway

New semantic entry points:

```python
editor.operation_schema()
editor.preflight_operations(operations, expected_project_hash=...)
editor.apply_agent_operations(operations, expected_project_hash=...)
```

HTTP equivalents:
- `GET /agent/operation-schema`
- `POST /agent/preflight`
- `POST /agent/apply`

The gateway normalizes allowlisted action aliases and common argument aliases, validates against the real Python function signature, surfaces nearby Library IDs, and dry-runs the normalized transaction before commit. Ambiguous artistic intent is never fuzzy-autocorrected.

The strict transaction API remains available and now converts bad Python call signatures into machine-readable `INVALID_OPERATION_ARGS`.

A deterministic 11-case LLM-style alias fixture produced 0/11 strict acceptance and 11/11 gateway preflight success. This is a regression fixture, not a real-model failure-rate claim.

## Semantic video modes

```python
editor.set_video_mode("4k60")
```

Supported common modes: 1080p30, 1080p60, 4k30, 4k60.

## UHD render profiles

- `uhd_4k30`: 3840×2160 @ 30 fps
- `uhd_4k60`: 3840×2160 @ 60 fps

Direct helper: `editor.render_4k60()`.

Alpha 9 used 2× supersampled cubic perspective for camera motion. Doing that at 4K60 would create an 8K60 intermediate. Alpha 10 preserves the 2× path for 720p/1080p compatibility while UHD uses native-resolution cubic perspective.

## Real render validation

A 0.6 s sample containing slow-push camera motion, dynamic cinematic bars and subtitle rendering produced a verified 3840×2160 / 60 fps / 36-frame MP4. It completed in about 10.1 s in the current CPU runtime; this is not a throughput guarantee.
