# AgentCut v0.2.0-alpha.5 — Library Expansion

This iteration focuses on **content-library growth without bloating the core**.

## Built-in library counts

- 39 transitions
- 24 semantic environment-effect presets
- 14 filters
- 12 camera-motion presets
- 12 layer-motion presets
- 8 subtitle styles
- 8 audio cues
- 12 procedural materials

**Total: 129 queryable entries.**

## Core/library separation

The canonical project/history/timeline/render-DAG code does not need to know every style by name. Content lives in JSON catalogs under `libraries/` and is queried through `Editor.list_library()` / `Editor.inspect_library_item()`.

Semantic preset helpers:

- `apply_effect_preset(scene_id, preset_id, ...)`
- `apply_motion_preset(scene_id, preset_id, ...)`
- `apply_transition_preset(scene_id, preset_id, ...)`
- `add_filter(scene_id, filter_id)`

## Procedural effects

New/expanded primitives include `sparks`, `fire`, `smoke`, `ash`, and `bokeh` in addition to snow/rain/dust/fog/embers/light-particles.

The library contains semantic presets such as `snow_wind`, `blizzard`, `dust_motes`, `fog_dense`, `campfire_sparks`, `smoke_dense`, `floating_ash`, `bokeh_warm`, and `glow_orbs`.

No third-party binary particle textures are bundled. Effects are deterministic Pillow/Numpy renderers with seeded output.

## Faster particle path

Soft effects render to lower-resolution intermediate proxy videos and are scaled only during final composition. Black-background particle assets are composited with RGB `colorkey -> alpha -> overlay`, avoiding expensive full-resolution RGB screen blending.

## Showcase render profile

`showcase` keeps a native 1920x1080/30fps canvas but uses faster H.264 parameters for rapid product demos and iteration.
