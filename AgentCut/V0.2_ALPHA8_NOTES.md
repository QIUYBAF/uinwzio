# AgentCut v0.2.0-alpha.8 — Visual Reframing That Reaches the Render

Alpha.8 is deliberately practical: it fixes the gap between “the Agent knows where the subject is” and “the renderer actually protects the subject”.

## Focus-aware real crop

`composition.focus_x` / `focus_y` now drive the actual FFmpeg `cover` crop. Alpha.7 could plan focus, but cover rendering still center-cropped.

Explicit asset tags remain authoritative and override inferred saliency.

## Deterministic visual analysis

```python
visual = e.analyze_visual("hero")
visual = e.analyze_scene_visual("scene_04", sample_count=3)
```

The lightweight analyzer estimates focus centroid, subject bounds, confidence and nine-zone visual occupancy from local contrast, edges, saturation and a weak center prior. It is deterministic saliency estimation, not semantic object recognition.

## Dynamic subject tracking

Continuous focus motion produces a normalized `focus_path`; the real crop interpolates it over scene time. A discontinuity guard suppresses synthetic tracking when focus jumps are too large, avoiding artificial whip-pans across internal cuts or saliency handoffs.

## Subject crop-risk protection

When a nominal `cover` crop would likely remove salient content, auto composition can choose `native_window` with `reason=subject_crop_risk`.

## Visual-safe text

The saliency pass scores nine text zones. Scene-relative dialogue can use:

```python
e.add_dialogue_segment("scene_01", "字幕", start=0.2, duration=1.5, position="auto")
```

## Practical bulk workflow

```python
e.auto_compose_scenes(sample_count=3)
```

CLI:

```bash
agentcut analyze-visual PROJECT ASSET_ID
agentcut composition-plan PROJECT SCENE_ID --analyze --text "title"
agentcut auto-compose PROJECT --scenes scene_03,scene_04 --samples 3
```

## Cache correctness fix

`composition` is now part of the scene render cache key. Framing edits can no longer accidentally reuse stale pixel output from a previous composition.

## QA additions

- `STACKED_REFRAME_CAMERA`: tracking and substantial camera motion are both active.
- `TEXT_SUBJECT_OVERLAP_RISK`: dialogue is outside visually quiet zones estimated for the scene.

## Validation

57/57 tests passed across grouped regression runs; `agentcut doctor` pass. Real focus-aware crop, real dynamic tracking and a three-scene integrated auto-composition smoke render all passed.
