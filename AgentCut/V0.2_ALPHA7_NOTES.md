# AgentCut v0.2.0-alpha.7 — Cinematic Composition

Alpha.7 turns several editing habits that previously lived only in agent judgment into deterministic semantic operations.

## Cinematic composition layer

Scenes can use a canonical `composition` object with four modes:

- `cover`: previous full-bleed crop behavior.
- `contain`: preserve the entire source inside the canvas.
- `native_window`: preserve the source's native aspect ratio as an intentional cinematic frame.
- `ambient`: keep a smaller sharp foreground over a blurred/dimmed full-frame background for low-resolution or strongly mismatched material.

Agent-facing helpers:

```python
plan = editor.suggest_composition("scene_04", text_hint="caption text")
editor.apply_auto_composition("scene_04", text_hint="caption text")
editor.set_composition("scene_04", mode="native_window", frame_scale=0.96)
```

The planner uses source geometry, target aspect ratio, resolution ratio and optional `focus_x` / `focus_y` asset tags. It returns a reason string so the decision is auditable.

## Composition-aware captions

Caption placement expands from three vertical slots to a nine-zone grid:

`top_left / top / top_right / left / center / right / bottom_left / bottom / bottom_right`.

`suggest_caption_zone()` places text away from the declared focal point, making embedded title-style text possible instead of forcing every caption to lower center.
