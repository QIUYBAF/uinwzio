# AgentCut Director 4.0.0 — Release Notes

## Product split

The 4.x generation is named **AgentCut Director**, distributed as `agentcut-director`, and invoked as `agentcut-director`. The existing 3.x runtime is referred to as **AgentCut Classic** and remains untouched.

## Initial stable surface

- CutGraph v1 canonical state.
- Atomic operations, preflight, receipts, expected-hash protection and undo.
- Semantic diff.
- Render-impact planning by domain and frame span.
- Remotion Bridge v1 export and strict integrity verification.
- Classic 3 non-destructive migration.
- Structural efficiency audit.
- Doctor and self-contained demo generation.

## Explicit non-claims

- Structural context/frame reduction is not reported as paid Codex-credit reduction.
- The generated Remotion source is verified locally, but a machine without installed npm dependencies has not executed Chromium rendering.
- Classic 3 projects are not modified in place.
