# AgentCut 电影化剪辑 Playbook — GLT V3

> 来源：2026-08《少女终末旅行》实验短片多轮重剪实践。
> 目标：把一次成功案例沉淀为可复用的 AgentCut / AI-native 视频剪辑方法，而不是保留成一次性技巧。

## 1. 核心判断

不要把素材之间的不统一当成需要“修复”的问题，而要把这种不统一变成一种可读的视觉语法。

推荐语义映射：

- 16:9 高清全幅：主叙事、现实、完整世界。
- 4:3：观察、记忆、安静段落、旧影像感。
- 2.39:1：高潮后的收束、终章、电影片尾感。
- 小画框 / 浮窗：档案、旧资料、低清素材、局部记忆。
- 多图拼贴：信息密度上升、高潮前 buildup、碎片化回忆。
- 黑场 / 负空间：为字幕与节奏服务，不是“没素材”。

## 2. 动态画幅不是转场特效，而是叙事动作

画幅变化本身应该承担意义：

- 4:3 → 16:9：世界突然变大、情绪释放、视野展开。
- 16:9 → 4:3：收缩、观察、进入记忆或档案状态。
- 16:9 → 2.39:1：章节收束、尾声、结论落地。

原则：

1. 不要每次切镜都变画幅。
2. 画幅变化应服务音乐拍点或叙事转折。
3. 画幅边缘不要机械线性运动。
4. 高反差 matte 在 30fps 下容易出现“格子感”，重要画幅/UI 动画优先用 60fps 计算。
5. 推荐 quintic smootherstep / cubic easing，让速度和加速度在起止端都平顺。
6. matte 可使用极轻 feather，避免硬边逐帧跳动。
7. 画幅动画可略微跨过剪切点，让它像同一个视觉对象在跨场景连续变形。

## 3. 低清素材的正确回收方式

低清素材不适合强行拉满 1920×1080。

正确用途：

- 缩小为“档案卡片”。
- 做成投影 / 照片 / 笔记页 / 监视器画面。
- 只裁取局部高价值细节。
- 在高潮段以 0.5–1.5 秒快速蒙太奇使用。
- 与高清素材形成“完整世界 vs 破碎记录”的对比。

错误用途：

- 模糊素材全屏停留 4–6 秒。
- 为了统一比例而强裁主体。
- 把旧字幕、时间码、拼板边缘直接带进主镜头。

## 4. 字幕不是字幕轨，而是版式元素

无配音视频尤其不应默认“字幕永远在下方”。

字幕应与画面共同构图：

- 4:3：利用左右黑场放文字。
- 16:9：利用天空、暗墙、空屏、道路等负空间。
- 拼贴段：文字可以成为卡片群的中心锚点。
- 强结论：允许独立占据黑场或负空间。
- 不让字幕压住人物脸、关键动作、光线中心。

字幕动画：

- 与画幅和音乐同频，不做独立“UI 动效”。
- 淡入淡出比大幅位移更稳。
- 关键句必须保证真实阅读时间，不能为了金句数量牺牲停留时长。
- 字体、字距、行距应根据具体镜头调整，而不是全片一个模板。

## 5. 音乐先行：节奏规划反过来决定画面

不要“先把画面剪完，再给音乐卡点”。

正确流程：

1. 分析 BGM 的能量曲线、onset、tempo、beat grid。
2. 找出低能量、平铺、抬升、高潮、退潮段。
3. 把叙事结构映射到音乐结构。
4. 场景边界优先吸附到附近 beat / onset。
5. 计算转场 overlap 后的真实时间线，避免视觉切点与音乐错位。

AgentCut Alpha 6 方向：

- `analyze_audio_rhythm()`
- `suggest_rhythm_cuts()`
- `rhythm_plan()`
- `apply_rhythm_plan()`

重要经验：

音乐后半段如果能量下降，而叙事在升高，哪怕卡点准确，整体仍然会“拧着”。

## 6. shared morph / shared element 是电影化 UI 的关键

跨镜头连续存在的对象，例如：

- 画框
- 标题
- 卡片
- 图片边界
- 某个视觉图标

不应在 A 场景淡掉、B 场景再复制一份出现。

应当把它视为同一个对象跨场景运动：

- position 连续
- scale 连续
- rotation 连续
- opacity 连续
- content 可 crossfade，但 geometry 保持一条运动轨迹

这就是 Alpha 6 `shared_morph` 最有价值的方向。

## 7. 静帧不等于必须一直动

这次最大的改进之一，是主动取消了大量没有叙事意义的 Ken Burns。

原则：

- 静帧可以静止。
- 运动必须有理由。
- 如果镜头只因为“怕死板”而推拉，通常会显得廉价。
- 真正有效的运动来源可以是：画幅、字幕、拼贴、对象层、光线、切换节奏，而不是每张图都 zoom in。

相机运动：

- 首选 subpixel perspective + cubic。
- 避免恒速 zoompan。
- 关键运动做逐帧速度检查，防止“先慢—突然快—突然停”。

## 8. 转场分级，而不是一种 transition 打天下

建议分层：

- 安静段：0.12–0.25s dissolve / fade。
- 实验/空间切换：可用极短 hblur / reveal。
- 情绪释放：接近硬切，依赖画幅扩张本身完成转场。
- 蒙太奇高潮：直接切，不让柔和 dissolve 削弱节奏。

判断标准：

> 如果去掉转场特效，画面仍成立，则转场大概率是对的。

## 9. 视觉押韵比“多素材”更重要

碎片素材应通过形状、方向、光线建立联系。

可复用例子：

- 锅的圆 → 镜片 → 月亮。
- 蒸汽 → 雾雪 → 尘埃。
- 书页线条 → 干涉条纹 → 道路灯光。
- 白光 → 彩虹 → 雪地反光 → 车灯。
- 按钮 → 实验开关 → 仪表盘。

这种匹配让“垃圾回收”从堆图变成电影语言。

## 10. 运动专项 QA

最终 QA 不只看有没有黑帧和音频错误，还要专门检查：

1. 画幅边缘是否逐帧跳动。
2. 转场前后主体位置是否突然改变。
3. 相机速度是否连续。
4. 字幕淡入是否与画面/音乐同频。
5. shared element 是否重复出现两份。
6. 低清素材是否被放得过大。
7. 重要字幕真实阅读时间是否足够。
8. 30fps 与 60fps 版本运动观感是否存在明显差异。
9. 音频 LUFS / True Peak 是否适合平台上传。
10. 全片 decode 是否 0 errors。

推荐：

- 60fps：用于动态画幅、UI、字幕等高反差运动层。
- 30fps：兼容副本。
- 不必把静帧本身插帧成“肥皂剧感”。

## 11. 停止条件

不要无止境“再加一点”。

只有在能明确指出以下内容之一时才继续修改：

- 一个具体的节奏错位。
- 一个明显的运动顿挫。
- 一个字幕构图问题。
- 一个主体被裁坏的问题。
- 一个音乐情绪与画面冲突的问题。
- 一个低清素材暴露的问题。

如果剩下的修改只是“更花”“更多”“更复杂”，而无法说明为什么会更好，则停止。

## 12. 本案例最终形成的系列剪辑语法

一句话总结：

> 不要修复素材之间的不统一，而要给这种不统一赋予语法。

系列默认语言：

- 16:9 = 主世界
- 4:3 = 记忆 / 观察
- 小窗 = 档案 / 低清残片
- 拼贴 = 信息加速 / 高潮 buildup
- 2.39:1 = 收束 / 终章
- 动态画幅 = 情绪动作
- 字幕 = 构图元素
- 音乐 = 时间线骨架
- shared morph = 跨场景连续对象
- 静止 = 被允许的电影动作

## 13. 下一阶段 AgentCut 产品化建议

应固化为可调用能力：

- `aspect_ratio_morph(from_ratio, to_ratio, duration, easing, feather)`
- `layout_caption(region='negative_space'|'side_matte'|'center')`
- `archive_card(asset, scale, border, grain)`
- `montage_grid(assets, rhythm_source, density)`
- `shared_morph(shared_id, ...)`
- `motion_qa()`：输出速度/加速度异常点
- `rhythm_plan()`：把场景边界吸附到音乐结构
- `cinematic_style_preset('glt_fragmented_memory')`

最终目标：让 Agent 不需要“学 Premiere”，而是能直接表达“我要这一段从观察态 4:3 打开成 16:9，并让右侧字幕随着 matte 一起退出”。
