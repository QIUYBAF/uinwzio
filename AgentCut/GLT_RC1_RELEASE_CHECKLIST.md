## 本轮最终整合

### 1. UI / 字幕
- 字幕继续作为构图元素，而不是底部说明文字。
- 字号略增，适配手机观看。
- 明亮雪景/灰白场景使用更深的“墨色”字幕语义；暗场使用暖灰白。
- 两个核心词做极轻强调：`问题`、`继续`，颜色来自棱镜光的暖色端，不做彩虹字。
- 降低字幕漂移幅度，主要依靠淡入淡出、留白和构图建立节奏。

### 2. 画面统一
- 维持 V3 的 4:3 / 16:9 / 2.39:1 动态画幅语法。
- 保留 soft matte + 60fps UI/画幅动画。
- 全片加入极轻微统一电影颗粒、暗角和低饱和色调，目的不是做“滤镜感”，而是让不同来源/不同清晰度素材处在同一个影像世界里。

### 3. 音乐 + 音效
原创器乐《还有问题》仍是绝对主体；音效作为“看不见的剪辑层”。

新增低电平声音设计：
- 0–5s：废弃实验室空气 + 棱镜玻璃泛音
- 5–10s：火焰/细微爆裂
- 10–15s：雪地风声
- 15–20s：售货机电流、按钮、提示音
- 20–25s：推车滚动与轻微金属震动
- 25–30s：煮面/沸腾
- 30–35s：档案/投影机空气感
- 35–50s：实验室低频 room tone、设备触发
- 50–55s：四次极轻“照片/档案”快门，对应蒙太奇节奏
- 55–60s：纸张/投影机
- 60–70s：棱镜泛音 + 双缝电子脉冲，贴合 BGM onset
- 70–80s：旅带车低频、夜风

动态画幅也获得对应的空间音效：
- 4:3 → 16:9：声音从中央向左右“打开”
- 16:9 → 4:3：更弱的向内收束
- 最后 2.39:1：不用普通 whoosh，而用低频“呼吸”收束

### 4. 音频安全
- 最终约 -15.6 LUFS
- True Peak 约 -2.5 dBFS
- LRA 约 8.9 LU
- 保留高潮动态，不做短视频式过度压缩
