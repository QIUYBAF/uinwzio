# AgentCut v0.2.0-alpha.6 — Shared Elements + Rhythm Planning

Alpha.6 moves AgentCut further above scene-level editing. The goal is to reduce both visual "PPT" behavior and agent planning overhead.

## 1. Rendered shared-element transitions

`shared_id` is no longer planning-only. Adjacent scenes can use:

```python
editor.set_transition("scene_a", "shared_morph", 0.6)
```

Layers with the same `shared_id` are suppressed from the ordinary scene overlays during the transition overlap and rendered once by a dedicated transparent morph overlay. Position, scale, opacity and rotation interpolate continuously; changed content crossfades while geometry continues along one motion path.

This prevents the common failure mode where the same card/title exists twice during a crossfade.

## 2. Lightweight rhythm analysis

Audio assets can now be analyzed without adding a heavy DSP dependency to AgentCut itself:

```python
analysis = editor.analyze_audio_rhythm("bgm")
# tempo_bpm, onsets, beat grid
```

FFmpeg decodes to mono float audio and NumPy computes a robust onset envelope + tempo estimate.

Agent-facing helpers:

```python
editor.suggest_rhythm_cuts("bgm")
editor.rhythm_plan(["s01", "s02", "s03"], "bgm")
editor.apply_rhythm_plan(plan)
```

The planner snaps semantic scene boundaries to nearby beats/onsets while enforcing minimum scene duration and accounting for transition overlaps.

## 3. Context Pack integration

Persisted rhythm analysis is summarized in `context_pack()` as compact tempo / beat-count / onset-count metadata. Agents do not need to re-read or re-analyze the whole audio file on every edit turn.

## 4. Library / validation

- transition library: 40 entries (new `shared_morph`)
- total queryable library entries: 130
- automated tests: 45/45 passed
- FFmpeg doctor: pass

## Known limits

- Shared morph currently interpolates 2D layer transforms, not arbitrary masks/paths/3D perspective.
- Text that changes between scenes crossfades while moving; glyph-level morphing is not implemented.
- Rhythm analysis is intentionally lightweight and deterministic. Complex swing, rubato, polyrhythm and weak-beat music may require a stronger optional analyzer later.
