# AgentCut 3.0.0 Release Notes

## Why 3.0 exists

Alpha 8–10 made AgentCut capable of real cinematic editing, but delivery remained profile-oriented. 3.0 closes that gap: export is now a semantic planning problem rather than a small set of fixed render commands.

## Flexible delivery

`ExportSpec` validates dimensions, frame rate, container, codec, encoder policy, quality and enhancement policy.

Real release validation includes MP4/H.264, WebM/VP9, MOV/ProRes, MKV/HEVC and the generalized 3840×2160@60 export route.

The output manifest records intended spec, selected encoder, enhancement plan, actual stages and ffprobe-verified result.

## GPU / NVENC planning

The planner distinguishes an encoder merely compiled into FFmpeg from one actually usable on the machine. `auto` prefers NVENC only after a real one-frame runtime probe; otherwise it selects a CPU encoder before the expensive export begins.

## AI enhancement adapters

### Real-ESRGAN
Optional super-resolution through the portable ncnn Vulkan backend. Anime content can select the anime-oriented model; general content uses the general model.

### RIFE
Optional frame interpolation through the portable ncnn Vulkan backend. AgentCut splits processing at canonical hard cuts to avoid deliberately synthesizing frames between unrelated shots.

### Fallback semantics
`auto`: use AI when installed and runtime-successful, otherwise record the fallback and use a deterministic non-AI path.

Explicit `ai` / `realesrgan` / `rife`: required backend failure is a machine-readable hard error; no silent degradation.

## Enhancement order

When both fps and resolution increase, the default recommendation is interpolation before super-resolution, reducing high-resolution interpolation work.

## Duration/spec invariants

Every export stage is probed. Enhancement is not allowed to silently shorten/lengthen the timeline; the final dimensions and fps are also verified before delivery.

## Compatibility

Alpha 8 visual composition, Alpha 9 cinematic grammar, Alpha 10 Reliability Gateway and legacy render profiles remain available. Export is additive and does not mutate canonical editing state.
