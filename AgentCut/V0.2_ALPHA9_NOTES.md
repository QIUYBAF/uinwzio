# AgentCut v0.2.0-alpha.9 — Cinematic Grammar

Alpha 9 adds editing grammar rather than another pile of decorative transitions. The goal is to let an Agent deliberately break continuity when impact, subject isolation, or fragmented memory benefits from it.

## 1. Dynamic cinematic frame

A scene can carry a normalized aspect-ratio path:

```python
e.set_cinematic_frame("s04", preset="scope_lock")
```

Built-in frame treatments:

- `scope_lock`: 16:9 gradually closes to 2.39:1.
- `scope_reveal`: 2.39:1 opens back to the full canvas.
- `impact_pulse`: rapid narrow/wide aspect pulse.
- `scope_hold`: hold 2.39:1 throughout the shot.

The renderer uses moving physical black bars. It does not resize project canvas or fake the effect in metadata.

## 2. Immediate optical close-up

Composition now supports `crop_zoom` in `[1.0, 3.0]`.

```python
e.set_composition("s04", mode="cover", focus_x=.32, focus_y=.61, crop_zoom=1.65)
```

This is an immediate focus-aware crop. It is intentionally separate from animated camera push/pull so a 3-frame close-up does not restart a Ken Burns motion.

## 3. Duration-preserving fragmentation

```python
e.fragment_scene("s04", style="impact_cluster", count=5, intensity=.85)
```

One visual-only scene becomes a micro-cut sequence while preserving total timeline duration and the original outgoing transition. The operation commits once and can be undone once.

Styles:

- `impact_cluster`: context → three escalating details → release.
- `detail_burst`: progressive close-up concentration around the focal point.
- `memory_shards`: non-linear source-time jumps for video, with alternating close-ups and aspect ratios.

Interior fragments are hard cuts by design. Their role is rhythm and association, not decorative transition spam.

## 4. Agent-facing treatment planner

```python
plan = e.suggest_cinematic_treatment("s04")
e.apply_cinematic_treatment("s04", style="auto")
```

The lightweight planner uses scene duration, current focal geometry and focus-path motion. Explicit style selection always wins.

## 5. Guardrails

- Fragmentation refuses scene-bound dialogue/audio/layers rather than silently damaging them.
- QA warns when dynamic framing is stacked with strong camera motion.
- QA warns when micro-fragments become too short to read as intentional edits.
- Very dense clusters are reported as an accent-use warning.

## 6. Bugs found by real editing

- Fixed cinematic overlay losing one video frame per treated scene. The renderer now pads two guard frames and trims back to exact scene duration.
- Fixed contact-sheet generation on newer FFmpeg builds by using PNG temporary frames instead of MJPEG.
- Contact sheets now use video-stream duration instead of overall container/audio duration.
- Fixed image metadata `format` strings being mistaken for media-duration dictionaries by `_asset_duration()`.
