# Workflow — 连载视频 / 动态漫单集

适用于 CT 系列。项目 PROJECT_HOME 的固定风格优先级高于本通用流程。

1. **一句话体验**：这集观众最应该感受到什么？只写一句。
2. **唯一剧情/内容目标**：这集必须推进什么；不要同时承担太多大目标。
3. **关键画面表**：先列 6–10 个关键画面/节拍，再制作素材。
4. **连续性检查**：人物、世界观、字幕、剪辑语言、色调与上一期的固定规则是否一致。
5. **最小粗剪**：先让对白、剧情和节奏成立，不先堆特效。
6. **第二层制作**：补必要运动帧、镜头运动、音效、转场、字幕。
7. **音乐**：最后加入；音乐不得压住对白与关键音效。
8. **一次最终 QA**：剧情/笑点或氛围 → 角色连续 → 画面 → 字幕 → 音量 → 开头/结尾 → 署名。
9. **发布包**：成片 + 16:9封面 + 4:3封面 + 标题 + 简介 + tags。
10. **回写**：发布后只把有证据的经验写回 PROJECT_HOME；一次表现波动不自动改系列核心。

## 停止点
通过最终 QA 后停止制作；不为不可见的小瑕疵无限返工。若需要大改固定风格，必须先记录 `CHANGES` 和理由。
