# Workflow — 纯手绘 / 插画

1. **选题**：回答“我想画什么 / 观众为什么看 / 最强记忆点是什么”。
2. **构图**：先做小草图和大形，不进入细节。
3. **锁结构**：人物姿态、透视、光源通过后才细化。
4. **锁色调**：先大色块，确认冷暖、明度层级和主体分离。
5. **人物制作**：主要以清晰色块与分区阴影推进；柔化只用于需要的部位。
6. **背景制作**：允许更多喷枪和空气感，但必须通过边缘、色调和光源与人物统一。
7. **统一处理**：最后专门检查人物/背景是否像两张图贴在一起。
8. **证据保留**：保留 Procreate 缩时、必要分层源文件；AI参考不替代手绘证据链。
9. **视频化**：只选构图变化、关键上色、重大修正和最终效果，不机械展示全部过程。
10. **发布包**：成图、过程视频、16:9封面、4:3封面、标题/简介、约稿说明（如需要）。

## 停止点
整体结构、色调、主体和关键细节成立后即可结束；不为极小局部无限重画。
