# OPS-01 B站运营与发布 — PROJECT_HOME

**STATUS:** ACTIVE  
**UPDATED:** 2026-09-01

## 1. 一句话目标
用真实数据和有限产能决定“下一周最值得做什么”，把制作、包装、发布、复盘和项目规则更新连成闭环，而不是让运营制造更多待办。

## 2. 项目身份 / PROJECT IDENTITY
### 核心体验
运营是创作系统的反馈层，不是生产力崇拜层。目标是让几个有长期价值的内容线逐步变强，同时避免为了追热点、凑频率或焦虑数据而不断切方向。

### 识别特征
- **少数稳定内容线**：优先维护 CT-01 少女终末旅行同人、CT-02 结束乐队×Minecraft、CT-03 纯手绘/插画；其他项目按证据进入 WAITING/ACTIVE。
- **每周决策而非每日摇摆**：主要方向在周决策会调整；日常数据只在出现显著变化或发布节点时介入。
- **一次只优化主要瓶颈**：区分选题、封面标题、前段留存、内容节奏、互动/转粉等，不因一个指标差就把所有东西一起改。
- **包装属于作品的一部分**：标题、封面、简介、tag 与开头必须准确表达真实内容，但不能用误导换点击。
- **连续性比追风口更重要**：成熟系列保持可识别体验；趋势只在与项目自然结合时利用。
- **发布后形成知识而非情绪**：复盘输出的是下一步动作与规则变化，不是反复刷新播放量。

### 可变化区
- 周更频率、直播次数、具体发布时间、标题结构、封面风格可以随近期数据和真实产能调整。
- 三条稳定线不要求每周硬凑齐；可以少做，但不能同时开太多重制作新坑。

### 不可无声变化
- 因单条视频表现差就宣布整个系列失败。
- 因热点临时把频道核心内容全面换轨。
- 用固定阈值机械判断所有视频，不看账号近期基线与内容类型。
- 为数据焦虑反复刷新、频繁重发/返工或一天内多次改变方向。
- 若运营结论要求改变某系列固定体验，必须回写对应 `PROJECT_HOME/CHANGES`，不能只在周报里说过就算。

## 3. 用户承诺
每周结束时应只留下少数清楚决定：唯一增长目标、不超过 3 个重制作主项目、每个项目唯一 NEXT、要暂停/归档的项目，以及至多一个最值得执行的运营动作。

## 4. 不可破坏约束
- 每周重制作主项目 ≤3；维护性小任务不应伪装成新主项目。
- 数据不足或平台不可读时明确写“未知/待回填”，不把缺失值当 0。
- 一次视频表现差先拆原因：选题 → 包装点击 → 前段留存 → 平均进度 → 互动/收藏 → 播转粉 → 流量来源。
- 封面默认准备 16:9 与 4:3 两版；移动端可读性属于最终 QA。
- 发布前只做一次完整终检；通过停止点后不因焦虑无限返工。
- 发布素材与数据结论回流项目真源，不把 B站本身当文件仓库。

## 5. 当前唯一交付物
每次周决策会输出下一周唯一增长目标、≤3 个主项目及唯一 NEXT，并顺带执行 ProjectOS 制度检查。

## 6. 标准发布/复盘线
1. 内容项目达到 DONE / 可交付状态。
2. 最终 QA：画面、字幕、音量、开头/结尾、署名、导出、AI/版权标识（如适用）。
3. 发布包：成片、16:9封面、4:3封面、标题、简介、tag、必要置顶评论。
4. 交付进入 Drive `02_发布交付/<项目ID>/<日期或EP>`。
5. 发布后记录首日/72h/7d关键数据；不要求无意义高频刷新。
6. 周会比较账号自身近期基线与同类内容，判断继续/扩大/改版/暂停/归档。
7. 一次只选最重要的结构性改进；若影响系列身份，写回对应项目 `CHANGES`。

## 7. ProjectOS 制度检查
- 重制作 ACTIVE 主项目是否 >3？
- 每个 ACTIVE 是否只有一个 NEXT？
- Drive/GitHub 是否出现多个平级“最新版”？
- DONE/旧版本是否应转 DELIVERY/ARCHIVE？
- 本周是否无意改变已定型项目身份？
- `99_待整理/99_收件箱` 是否长期积压？

## 8. 完成定义 DoD
增长目标明确；主项目≤3；每个主项目唯一 NEXT；发布包装齐全；应暂停/归档项明确；至少一条数据结论转化为行动或明确“无需行动”。

## 9. 文件真源

- **Drive:** `01_进行中/OPS-01_B站运营发布_ACTIVE` + `02_发布交付`

## 10. HANDOFF
**DONE:** 周决策会已与 ProjectOS 制度检查合并；频道当前围绕三条稳定内容线运作。  
**NEXT:** 下一次周会只确定一个增长目标和≤3个主项目，不新增平行管理任务。  
**BLOCKERS:** 某些 B站数据若不可直接读取，则以可获得数据为界，不猜。  
**CHANGES:** 2026-09-01 将“运营是反馈层、不是任务生成器”固定为项目身份。
