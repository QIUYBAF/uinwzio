# CT-01 她们仍在旅行 — PROJECT_HOME

**STATUS:** ACTIVE  
**UPDATED:** 2026-09-01

## 1. 一句话目标
用千户与尤莉持续穿行于废墟、城市、自然与知识遗迹的短片/插画，制造安静、荒凉、温柔而略带荒诞的末世旅行体验。

## 2. 项目身份 / PROJECT IDENTITY
### 核心体验
世界已经破败，但两个人仍然旅行、观察、吃饭、聊天、理解事物。宏大废墟与微小日常并置，情绪克制，不靠强行煽情制造“深刻”。

### 识别特征
- **空间感优先**：环境往往比人物更大，人物可以很小，让“人仍在世界里继续前进”成为视觉核心。
- **安静与留白**：镜头运动、字幕、音效和转场都偏克制；允许停顿，不能剪成高刺激信息流。
- **荒诞中的日常**：末世不是持续灾难展示，而是与吃饭、闲聊、实验、旅行等普通行为同时存在。
- **千户 / 尤莉关系稳定**：千户更谨慎、理性、负责推进；尤莉更活泼、随性、直接。二人的互补关系比单独卖角色更重要。
- **视觉连续**：角色发色、体型高差、脸部特征、服装逻辑、旅带车等标志物保持一致；具体服装可随地点/季节变化。
- **主题可以扩展**：旅行、城市、科学史、知识、死亡等都可以进入，但必须仍然像“她们在旅行中遇见这些东西”。

### 可变化区
- 地点、时代遗迹、季节、单集主题、色调、是否加入知识/科学内容。
- 单集可以偏轻松、哲思或纯氛围，但不能丢失二人关系与旅行感。

### 不可无声变化
- 从静谧氛围片突然变成高密度搞笑/快剪。
- 人物比例、性格、核心视觉设定大改。
- 相邻两期突然更换字幕体系、镜头运动哲学、色彩语言或整体动画方式。
- 若确需改变，必须在 `CHANGES` 写明“改了什么、为什么改、依据是什么”。

## 3. 观众承诺
每一期即使题材不同，也应让熟悉系列的观众在几十秒内认出：这是同一对人、同一个世界气质、同一套克制的影视语言。

## 4. 不可破坏约束
- 画面以氛围、构图与空间尺度优先，不为炫技塞无关镜头效果。
- 同系列相邻期保持剪辑、字幕、节奏的“家族相似性”。
- 镜头运动以缓慢推拉、平移、景深/轻微视差等服务观察感；不机械抖动。
- BGM 是情绪底层，不能压住环境声与对白；结尾可以留黑/停顿形成余韵。
- 封面默认准备 16:9 与 4:3 两版。

## 5. 当前唯一交付物
每期开工前先确定“一句话体验 + 6–10 个关键画面”，再进入正式制作。

## 6. 标准工作流
1. 定一句话体验与本集主题。
2. 列 6–10 个关键画面，先锁地点、角色状态、色调、镜头尺度。
3. 做低成本构图/参考，确认后再出最终画面，避免中途反复推翻角色。
4. 先保证画面连续，再补必要镜头运动、环境声、字幕、BGM。
5. QA：角色一致性 → 空间/情绪连续 → 字幕 → BGM/音效 → 封面。
6. 发布后把有效反馈回写 OPS-01；只有明确证据才修改长期规则。
