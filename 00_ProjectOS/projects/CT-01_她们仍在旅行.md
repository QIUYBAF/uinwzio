# CT-01 她们仍在旅行 — PROJECT_HOME

**STATUS:** ACTIVE（本周低负担备选）  
**UPDATED:** 2026-10-26

## 1. 一句话目标
用千户与尤莉持续穿行于废墟、城市、自然与知识遗迹的短片/插画，制造安静、荒凉、温柔而略带荒诞的末世旅行体验。

## 2. 项目身份 / PROJECT IDENTITY
### 核心体验
世界已经破败，但两个人仍然旅行、观察、吃饭、聊天。宏大废墟与微小日常并置，情绪克制，不靠强行煽情制造“深刻”。

### 识别特征
- 环境尺度大、人物可小；空间感优先。
- 镜头、字幕、音效克制，允许停顿与留白。
- 千户理性谨慎、尤莉随性直接；二人关系比单独卖角色更重要。
- 发色、体型高差、脸部、服装逻辑与旅带车保持连续。
- 题材可以扩展，但必须像“她们在旅行中遇见这些东西”。

### 可变化区
地点、遗迹、季节、单集主题、色调、知识密度可变；单集可轻松、哲思或纯氛围。

### 不可无声变化
不得突然转高密度快剪、重置人物性格/视觉、无说明更换字幕与动画体系；稳定规则变化必须写入 CHANGES。

## 3. 观众承诺
几十秒内认出同一对人、同一世界气质与同一套克制影视语言。

## 4. 不可破坏约束
构图与空间优先；慢推拉/轻视差服务观察感；BGM 不压环境声/对白；封面默认 16:9 与 4:3 两版。
