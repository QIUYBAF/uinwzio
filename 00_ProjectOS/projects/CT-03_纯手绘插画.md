# CT-03 纯手绘 / 插画视频 — PROJECT_HOME

**STATUS:** ACTIVE  
**UPDATED:** 2026-09-01

## 1. 一句话目标
让真实手绘作品与绘画过程本身成为内容价值，逐步形成稳定、可识别的个人视觉语言，并自然服务频道增长与约稿。

## 2. 项目身份 / PROJECT IDENTITY
### 核心体验
观众看到的不是“AI替我画完”，而是一个真实创作者如何从构图、色块、人物、背景一路把画面做出来；作品完成度与个人审美比制作噱头更重要。

### 识别特征
- **人物偏清晰、非连续的色块语言**：底色与阴影按区域组织，少用大面积连续软阴影；柔化主要留给腮红、关节血色和少量局部过渡。
- **背景偏空气与氛围**：喷枪/软笔建立光、雾、天空、空间，再用必要线条或硬边把结构拉回来。
- **人物与背景存在有意反差**：目标不是把两者强行画成完全同一种笔触，而是通过综合色调、边缘、光源与局部硬软关系让它们属于同一张画。
- **二次元角色是视觉核心**：人体、透视、姿态、表情和服装辨识度优先；背景服务人物与主题，而不是喧宾夺主。
- **过程证据是真实价值的一部分**：保留 Procreate 缩时、分层文件和关键阶段，既服务视频，也形成约稿可信度。
- **AI是草图桌，不是署名者**：可用于构图参考、方案探索、透视/氛围参考，但最终作品和关键绘制过程必须由手绘成立。

### 可变化区
- 题材可在《少女终末旅行》、孤独摇滚联动、战地、校园、原创等之间变化。
- 笔刷、背景手法、边缘处理可以逐步实验；允许形成新技法，但要保留作品连续性。

### 不可无声变化
- 把最终作品变成 AI 生成图再包装成手绘。
- 为追求统一而抹掉人物色块语言，或反过来把背景全部硬切成与人物一样的块面。
- 每幅画都重新发明一套完全不同的视觉体系。
- 为视频节奏牺牲画面质量，或因完美主义无限重画同一处。

## 3. 观众承诺
每期至少让观众获得一个真实作品结果、一个有信息量的绘画过程和一个清楚的视觉记忆点；即使题材不同，也能逐渐认出是同一位作者的画。

## 4. 不可破坏约束
- 开始前先确定主题、构图和最强记忆点，不直接陷入局部细节。
- 锁定人体/透视/光源后再细化，避免后期结构性返工。
- 人物与背景的统一优先从色调桥梁、边缘处理、光源关系解决，而不是整体推翻画法。
- 过程视频只保留有变化/有信息的阶段，不做无脑全程倍速。
- 封面默认 16:9 + 4:3；手绘成图本身应是主要点击资产。

## 5. 当前唯一交付物
在后续代表作中验证“色调桥梁 + 边缘统一”方法，减少人物与喷枪背景的割裂感，同时保留两套笔法各自优势。

## 6. 标准工作流
1. 选题：想画什么 / 为什么值得看 / 一眼记住什么。
2. 低成本构图 + 大色块；先确定视线、透视和主体占比。
3. 锁人体、姿态、服装、光源后进入人物色块与分区阴影。
4. 背景先空气/空间，再补必要结构硬边与线条。
5. 用综合色调、边缘、反光和局部柔化连接人物与背景。
6. 最终检查：人体 → 透视 → 明暗层级 → 色彩 → 主体突出 → 小瑕疵停止点。
7. 从缩时中抽取真正有变化的阶段制作视频并打包发布素材。

## 7. 完成定义 DoD
最终成图可独立作为作品；过程证据完整；视频有明确创作过程而非机械倍速；达到停止点后不为微小瑕疵无限返工。
