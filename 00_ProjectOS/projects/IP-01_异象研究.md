# IP-01 异象研究 — PROJECT_HOME

**STATUS:** WAITING

## 目标与观众承诺
原创校园异常调查 IP。核心体验是“现实像代码偶尔出错”：异常来自日常环境的细微失真，而不是靠说明书式世界观堆砌。

## 不可破坏约束
- 许念 / 林见微 / 周晚晴的人物关系与视觉设定连续。
- 先让观众看到异常、产生疑问，再逐步解释；避免大量前置说明。
- 每集必须有一个可感知的异常现象、一个人物反应/关系推进、一个后续钩子。
- 恐怖/悬疑来自熟悉事物的偏差，不靠无意义血腥或突然大声刺激。

## 标准工作流
1. 写本集“正常规则”。
2. 只设计一个主要异常，并说明它怎样违反正常规则。
3. 用人物行动发现异常，不用旁白一次讲完。
4. 分镜按：日常建立→异常首次出现→验证/升级→人物选择→余波/钩子。
5. 先做最短可成立版本，再决定是否扩展世界观。
6. 发布后只根据观众是否理解异常、是否愿意追后续来调整信息密度。

## 完成定义
异常机制清楚但不过度解释；人物有实际行动；单集可看且留下连续性；设定变更已回写。
