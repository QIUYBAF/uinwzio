# IP-01 异象研究 — PROJECT_HOME

**STATUS:** WAITING  
**UPDATED:** 2026-09-01

## 1. 一句话目标
做一个以校园/日常环境为基底的原创异常调查 IP：现实并未彻底崩坏，而是像代码一样偶尔出现细小、可验证、令人不安的错误。

## 2. 项目身份 / PROJECT IDENTITY
### 核心体验
熟悉的现实先成立，然后只错一点点。观众先察觉“不对”，再跟人物一起验证规则、承担选择，而不是先听一段世界观说明。

### 识别特征
- **异常来自规则偏差**：时间、空间、物体、记忆、重复、因果等日常规则出现可观察错误，比直接出现怪物更重要。
- **校园/日常是锚点**：越普通、越熟悉的场景发生细微失真，越符合项目气质。
- **先展示后解释**：镜头、人物行动和重复验证承担信息，旁白/设定说明只补必要部分。
- **人物关系必须推进**：许念、林见微、周晚晴等人物不是“解谜工具人”；异常应暴露性格、信任、选择或代价。
- **克制悬疑**：恐怖来自认知失配和不可确定性，不依赖廉价 jump scare、血腥或持续高噪音。
- **每个异常有规则**：哪怕观众暂时不知道完整解释，作者侧也必须知道“正常规则是什么、异常如何违背、验证方式是什么”。

### 可变化区
- 单集可偏悬疑、科幻、校园、动作或人物关系；异常规模可从一间教室到更大范围。
- 视觉表现可做动态漫、水墨/粒子等实验，但必须服务异常机制，而不是取代叙事。

### 不可无声变化
- 变成大量世界观名词、组织设定和旁白堆砌。
- 让异常没有可观察规则，只靠“作者说它很神秘”。
- 为刺激而突然转向纯血腥恐怖。
- 角色关系和已确认视觉设定大幅漂移。
- 技法实验若影响系列视觉身份，必须记录 `CHANGES`。

## 3. 观众承诺
每一集至少提供：一个能被观众感知的异常、一次人物主动验证/应对、一个关系或选择上的变化，以及一个不过度解释的后续钩子。

## 4. 不可破坏约束
- 先建立正常规则，再违反它。
- 信息密度以“观众能跟上异常”为标准，不追求一次讲完世界。
- 同一异常先用最少镜头证明它成立，再决定是否升级。
- 视觉特效必须指向异常本身；不能用大量水墨/粒子掩盖动作或连续性问题。
- 连续动作实验先做角色锚点和少量样片，验证失败前不批量生成。

## 5. 当前唯一交付物
项目恢复时，先做一个短小、少说明、靠视觉异常即可成立的单集原型，再决定是否扩大制作规模。

## 6. 标准工作流
1. 写一句“正常情况下应该怎样”。
2. 定义唯一主要异常：违反哪条规则、人物如何第一次发现。
3. 设计最少验证动作，让人物亲自确认异常而非听别人解释。
4. 分镜：日常建立 → 首次偏差 → 验证/升级 → 人物选择 → 余波/钩子。
5. 先做关键角色锚点和 2–3 个连续样片，检查人物/手/武器/空间连续性。
6. 样片成立后再批量推进；不成立先修规则或镜头，不扩大错误。
7. 发布后重点观察“观众是否看懂异常、是否想知道后续”，再调整信息密度。

## 7. 完成定义 DoD
异常机制在画面中成立；人物有主动行动；单集即使不读设定文档也可观看；留有后续但不过度解释；视觉连续性通过。
