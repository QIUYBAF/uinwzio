# SW-02 RNGtuber — PROJECT_HOME

**STATUS:** ACTIVE

## 目标与用户承诺
做一个 Windows 可直接运行的透明窗口 PNGTuber/RNGtuber：角色资产模块化，输入/麦克风/眨眼/表情稳定，优先“直播可用”而不是无限堆功能。

## 不可破坏约束
- 角色资产统一画布与坐标，不允许通过手工偏移修补长期错位。
- Base、眼、眉、嘴、瞳、发饰、手柄等模块必须独立、真透明、同坐标。
- 状态切换不能闪烁；表情/服装切换允许短淡化但不能跳位。
- 麦克风触发必须可调阈值与平滑，不因环境噪声高速抖动。
- 打包 EXE 是实际交付目标，不能长期停在开发环境演示。

## 标准工作流
1. 先锁定资产坐标规范，再制作/替换素材。
2. 用最小状态矩阵验证 idle/talk/blink/blink_talk。
3. 再扩展表情与两套服装。
4. 实现输入映射、麦克风、透明窗、快捷键。
5. 做切换平滑与必要动态效果。
6. Windows 本地打包并实际启动验证。
7. 成功构建进入 Drive ACTIVE；旧构建归档，不让多个 EXE 并列为“最新版”。

## 完成定义
角色无明显错位/残影；麦克风与眨眼稳定；快捷键有效；Windows EXE 可直接启动；当前构建与资产真源位置明确。
