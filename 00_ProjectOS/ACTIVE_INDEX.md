## 调度规则

- 本表只回答“有哪些项目、状态是什么、PROJECT_HOME 在哪”。固定核心、文件真源、NEXT 和约束由各自 PROJECT_HOME 负责，避免双重维护。
- 重制作主项目每周最多 3 个；其余可维护但不抢占主线。
- 新想法默认 WAITING / INBOX。
- 每个 ACTIVE 项目必须只有一个 NEXT。
- 每周决策会负责继续 / 改版 / 暂停 / 归档。

## 命名

聊天、handoff、Drive 与本地目录尽可能保留稳定 Project ID；版本号属于 Git tag/release/archive，不创建新的平级“最新版”项目。
