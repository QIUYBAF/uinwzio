## 分组建议

### ChatGPT Groups
- `CT｜内容制作`
- `SW｜软件研发`
- `OPS｜运营发布`
- `LAB｜学习研究`
- `ARCHIVE｜暂停项目`

聊天标题一律以项目编号开头，例如：`CT-01 EP12 构图与脚本`。

## 当前调度规则

- 一周真正推进的“重制作主项目”最多 3 个；其余项目可维护，但不能抢占主线。
- 新想法默认进入 WAITING/INBOX，不自动升级为 ACTIVE。
- 每个 ACTIVE 项目必须只有一个 `NEXT`；没有 NEXT 的项目视为未完成交接。
- 每周决策会负责：继续 / 改版 / 暂停 / 归档，而不是不断新增项目。
