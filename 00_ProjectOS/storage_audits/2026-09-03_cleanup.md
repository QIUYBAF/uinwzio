## 目标
按 Project OS 的平台职责与文件生命周期整理 ChatGPT Library、Google Drive 与 GitHub：

## 停止点

本轮整理在以下边界停止：

1. 正式入口与主要大文件已归位；
2. Library 不再承担母版/工程包仓库职责；
3. Drive 根目录保持干净，未知资产集中到待识别区；
4. 小型 Legacy 散件不继续无休止逐个辨认；
5. 不在缺少备份与明确授权时重写 Git 历史。
